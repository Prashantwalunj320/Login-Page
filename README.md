Simple Login Page:
This project is a simple and responsive Login Page created using only HTML and CSS. It is designed for beginners to understand basic structure, styling, and layout techniques.
🚀 Features
Clean and modern UI
Responsive design
Input fields for username and password
Styled login button
Basic form layout using HTML & CSS only
🛠️ Technologies Used
HTML5
CSS3
📂 Project Structure
login-page/
│── index.html
│── style.css
⚙️ How to Use
Download or clone the repository
Open index.html in your browser
View the login page
